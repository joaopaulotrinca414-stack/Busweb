# Bus-Webs
Sistema desenvolvido referente a semana Ideathon da FATEC Centro Paula de Souza unidade de Araçatuba.

Tema para Ideathon utilizado "Mobilidade Urbana e Sustentabilidade".

Tivemos a ideia de gerir um site onde mostre as diferenças entre a utilização de ônibus eletrico, o mesmo mostra a poluição criada pelo convencional contra a gerado pelo elétrico.
